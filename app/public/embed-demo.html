Integration Level 1 · Script Tag Embed

Savanna Partner Portal — Host Integration Demo

This page simulates an external portal embedding OpenPath with a single <script> tag. It features auto-resizing (zero inner scrollbars), microphone permissions delegation, and bidirectional postMessage event communication.

How to embed this on any website (HTML code) 
<!-- 1. Target container on your host page -->
<div id="openpath-signup"></div>

<!-- 2. One script tag to load and run -->
<script src="https://openpath.example.et/embed.js"
        data-form="onboard"
        data-lang="am"
        data-target="#openpath-signup"
        data-title="የተማሪ ምዝገባ ቅጽ">
</script>
